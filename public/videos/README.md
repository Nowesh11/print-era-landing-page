# Hero video

Put the hero background video here. The hero section (`src/components/sections/hero.tsx`) expects:

| File | Notes |
| --- | --- |
| `hero.webm` | VP9/AV1, 1920×1080, 10–20 s seamless loop, **no audio track**, ideally < 4 MB |
| `hero.mp4` | H.264 fallback, same cut, ideally < 6 MB |
| `hero-poster.jpg` | First frame as a still (also used under reduced motion and on save-data), < 200 KB |

Optional: `hero-mobile.mp4` (720×1280 portrait crop) for phones.

Content: real Print Era footage (the printer working on a wall, close-ups of ink, a finished room reveal). Never use footage from wallzen.ae or other sites.
